# 后台精简、限制修复与数据库清理记录

日期：2026-11-06。对应 [计划](admin-simplification-plan.md)。修改已在仓库完成；没有操作正式数据库或 NAS，没有发布镜像、提交或推送 Git。

## 实际结果

- 后台只有概览、文件管理、系统设置。原 NAS/MCP 书签转至概览，专用管理 API 已删除并返回 JSON 404。
- 文件管理仅保留搜索、状态筛选、分页、只读详情、下载和单项/批量删除；下载和删除复用 Relay 生命周期与租约。
- 后台设置、公开配置、首页预检、服务端新建/分片/合并/发布和概览统一读取 `upload_size`、`storage_limit`、`open_upload`。超限返回 413，额度或磁盘不足返回 507。
- 单文件默认 1 GB、全站默认 500 GB，可调低；单位统一十进制，旧字节值精确保留。已发布文件不因降额删除，在途上传的规则见运行说明。
